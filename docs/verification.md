# 验证说明

## 已有验证

Windows x64、Python 3.13.9、PySide6 6.9.2。已对本地版本的统计、定位与恢复逻辑运行 55 项离线测试，并通过以下检查：

- 11 项 Qt 界面检查：模型与强度卡片、宽度、刷新、切换、滚动及窄窗口处理。
- 16 项原生窗口层级检查：普通及置顶前台窗口、所属关系、可见状态、焦点、最小化与还原。
- 10 项安装后的实际后台检查：保持原会话、后台可见、位于 Codex 上方及其他应用下方、保留焦点与 Codex 进程。
- Codex `26.928.1915.0` 的调试连接、会话路由与完整输入栏空位读取。
- 10 项新版恢复流程检查：等待手动退出、保留进程、恢复连接与会话、显示用量条、完成进程移交。
- 7 项安装后恢复等待检查：重复启动、停止、取消后保留 Codex、再次进入等待。

统计验证使用合成数据和已有日志，不为验收额外提交模型请求。真实日志、会话标识、用户目录、浏览器配置与失败诊断仅保留在本机，不包含在公开仓库或发行包中。

## 公开版本

公开版本保留统计、定位与恢复逻辑，安装器改为注册本产品独立市场。新增安装器和发布包清单检查，测试结果见 GitHub Actions 与发行包的 `validation-summary.json`。CI 不访问用户日志、不启动 Codex、不发送模型请求。

## 尚未完成

跨物理屏幕的混合 DPI 和两个真实会话窗口同时运行未完成完整实机验收。逻辑测试包含负坐标、DPI/缩放换算、最大化窗口边框和同尺寸辅助窗口误绑定防护。

内部路由、DOM 标识和调试接口可能随 Codex 更新发生变化。无法确认会话或空间不足时隐藏并显示原因；不会根据最近活跃的会话猜测。
